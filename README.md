## Visão Geral 📋

O **Projeto Livraria Virtual** teve início como um protótipo acadêmico, concebido para explorar conceitos fundamentais de desenvolvimento web e boas práticas de engenharia de software. Com o passar do tempo, evoluiu para se tornar um projeto mais robusto, direcionado a servir como **portfólio técnico**, demonstrando competências em arquitetura de sistemas, documentação e implementação de soluções escaláveis. Atualmente, o sistema é estruturado como uma **Single Page Application (SPA)** integrada a uma **API REST**, utilizando **MongoDB** como banco de dados para garantir flexibilidade e desempenho.

## Tecnologias Utilizadas 💡

* **HTML5**: Estrutura semântica e acessível para o conteúdo.
* **CSS3**: Estilização responsiva e moderna, com foco em usabilidade.
* **JavaScript**: Implementação de funcionalidades dinâmicas e interativas.
* **React**: Biblioteca para construção de interfaces de usuário reativas e componentizadas.
* **Next.js**: Framework para React que adiciona funcionalidades avançadas como renderização híbrida (SSR/SSG) e otimização de desempenho.
* **SPA**: Arquitetura de aplicação de página única para melhor experiência do usuário.
* **API REST**: Comunicação padronizada entre cliente e servidor.
* **MongoDB**: Banco de dados NoSQL para armazenamento eficiente e escalável.

## Arquitetura 📐

A aplicação segue princípios de modularidade e separação de responsabilidades, permitindo fácil manutenção e evolução futura. O projeto foi estruturado para suportar integrações e extensões, mantendo a qualidade do código e a clareza arquitetural.

## Funcionalidades Principais ⚙️

* **Front-end Responsivo:** Interface desenvolvida com foco em **design adaptativo**, garantindo usabilidade consistente em dispositivos móveis e desktops.
* **Integração com Banco de Dados:** Conexão com **MongoDB** para armazenamento e consulta de informações sobre livros, permitindo operações eficientes de leitura e escrita.
* **Catálogo com Paginação:** Implementação de paginação dinâmica na página de **Acervo**, otimizando a exibição de grandes volumes de dados e melhorando a experiência de navegação.
* **Filtros de Consulta:** Sistema de filtragem por categorias de leitura, oferecendo uma experiência personalizada e relevante para o usuário.
* **Ordenação de Resultados:** Exibição inicial na página **Home** com listagem dos livros mais vendidos em ordem decrescente, utilizando consultas otimizadas na API.
* **Carrinho de Compras:** Funcionalidade completa de gerenciamento de itens, incluindo adição, remoção, persistência via **localStorage**, e notificações sobre quantidade e status dos produtos.

## Evolução 🚀

O projeto recebe melhorias significativas e novas funcionalidades estão planejadas para elevar o escopo técnico e profissional.

**Próximas Atualizações:**
* **Documentação com Swagger**: Implementação de documentação interativa e padronizada para APIs, facilitando o entendimento e a integração por desenvolvedores.
* **Aplicação de princípios Clean Architecture**: Reestruturação da base de código para garantir maior desacoplamento, testabilidade e escalabilidade, promovendo boas práticas de engenharia de software.

**Funcionalidades futuras:**
* **Autenticação de Usuários:** Implementação de mecanismos de login e controle de sessão, garantindo segurança e personalização da experiência.
* **Cadastro de Usuários:** Criação de fluxo completo de registro, permitindo que novos usuários criem contas, gerenciem seus dados e acompanhem suas atividades dentro da plataforma.

## Objetivos 🎯

* Consolidar o projeto como um **portfólio técnico** representativo das habilidades adquiridas.
* Demonstrar a aplicação prática de conceitos acadêmicos em um ambiente real de desenvolvimento.
* Servir como base para futuras evoluções, integrando novas tecnologias e padrões de mercado.
* Evidenciar competências em **SPA**, **API REST** e **Banco de Dados** como parte da formação técnica.
* Oferecer documentação clara e acessível para desenvolvedores e colaboradores.

## Conclusão 📌

O **Projeto Livraria Virtual** está em constante evolução, incorporando práticas modernas de desenvolvimento e arquitetura de software. As novas modificações destacam o compromisso com qualidade, escalabilidade e experiência do usuário, reforçando seu papel como vitrine técnica e acadêmica.
